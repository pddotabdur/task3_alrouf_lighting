# Installation & Safety Notes (Sample)

This document is a sample knowledge-base file used for the Task 3 RAG demo.

## Electrical Safety
- Installation must be done by qualified electricians.
- Ensure proper grounding and surge protection as per site standards.

## Pole / Fixture Compatibility
- Confirm the pole spigot/arm dimension matches the fixture bracket.
- For coastal areas, anti-corrosion coating may be required.

## Maintenance
- Keep lens/glass clean for optimal lux levels.
- Replace damaged gaskets to maintain IP rating.
